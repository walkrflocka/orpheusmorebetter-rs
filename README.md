# OrpheusMoreBetter-rs

A rust rewrite of [orpheusmorebetter-py](https://github.com/walkrflocka/orpheusmorebetter). This software is currently in alpha, and has the API interop with Orpheus's login systems built out, but no transcoding, configs, caching, or uploading - yet.
This is intended to eventually replace `orpheusmorebetter-py` once this binary has reached feature parity.
